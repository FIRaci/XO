# Project Roadmap

## Phase 1: Core Engine & Minimalist UI (Hoàn thành)
- [x] Bàn cờ tùy biến kích thước từ 3x3 đến 15x15.
- [x] Thuật toán kiểm tra thắng: $N \le 4$ cần $N$ ô, $N \ge 5$ cần 5 ô (Caro chuẩn).
- [x] Hệ thống chọn màu cho X và O có cơ chế chống trùng màu.
- [x] Giao diện tối giản phong cách monochrome trắng đen.
- [x] Easter Egg phím tắt `Alt + A` hiển thị trích dẫn đặc biệt.
- [x] Cấu hình triển khai tự động Vercel.

## Phase 2: Feature Expansion (Tương lai)
- [ ] Chế độ chơi với AI (Minimax cho 3x3 và Heuristic evaluation cho bàn cờ lớn).
- [ ] Tính năng Undo / Redo nước đi.
- [ ] Âm thanh click phím gỗ tối giản (Minimalist wooden sound effects).
- [ ] Chế độ chơi Online qua WebRTC Peer-to-Peer.
